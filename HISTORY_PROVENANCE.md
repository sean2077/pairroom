# Git History Provenance

The v0.1.0, v0.2.0, and v0.3.0 commits in this repository were reconstructed from the corresponding complete release source snapshots after the original temporary development `.git` directory was no longer available.

The reconstructed commits preserve the released file contents and milestone order, but their commit hashes differ from the original temporary development hashes. The original v0.3 release record referenced commit prefix `9500f99`; it is retained here only as historical provenance and must not be treated as an object available in this repository.

All work from v0.4.0 through v1.0.0 was developed, tested, and committed directly on the retained `release/v1.0.0` Git history contained in the full package.
