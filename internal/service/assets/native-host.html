    Connect a session

    Use the commands in each slot, approve the project hook, then echo the one-time bind nonce in the native session. Existing native work is never stopped by replacing a binding.

    pairroom relay status --room … --slot …

    pairroom relay peer --room … --slot …

    To recover the same session, bind with --continue --session-id <associated ID>. A different session needs explicit --replace.

    Retry uncertain delivery?

    Inspect the Event Log and workspace first. The original may already have been used. Retry creates a new message ID and can duplicate native work.
