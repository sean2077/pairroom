# Grok Build

Read this when the current Runtime is Grok.

Approve `/hooks`, reload with `r`; folder trust is the human's. Reuse a compatible project hook; do not add a duplicate.

There is no Service wake and at most seven Stop continuations. Long unattended runs need tracked completion: one background wait in Grok, long results sent explicitly, else input stays queued. Read the waiting guidance linked from SKILL.md before starting that collector.

Readiness means run `pairroom relay wait` for full input. Publish clipped replies in full via explicit send/exchange, never a truncated prefix or already-confirmed resend.

Grok shell mode (`!`) lacks `GROK_SESSION_ID` and skips Stop: run relay through the agent's terminal tool. If the human used `!`, rerun it yourself; never ask for a session ID.
